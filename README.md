# AI Prompt Generator

A single-page web application for generating optimized AI prompts for text, image, and video generation.

## Features

- **Text Prompt Generation** — Create structured prompts for text-based AI models
- **Image Prompt Generation** — Build detailed prompts for AI image generators
- **Video Prompt Generation** — Craft prompts for AI video generation tools
- **Light/Dark Theme** — Toggle between light and dark modes
- **Advanced Techniques** — Supports RAG, Chain of Thought, Tree of Thought, and other prompting strategies
- **Favorites System** — Save and manage your best prompts
- **Rating System** — Rate generated prompts for quality tracking

## Tech Stack

- HTML5, CSS3, JavaScript (vanilla)
- Tailwind CSS (CDN)
- Font Awesome icons
- Google Fonts (Inter)
- No build step required — just open `index.html`

## Usage

1. Clone the repository
2. Open `index.html` in your browser
3. Select a prompt type (Text / Image / Video)
4. Configure your parameters and generate
